# Club Esportiu - Proyecto Web 

Sistema de gestión web desarrollado en Java y HTML/CSS para la asignatura **EI1027** de la Universitat Jaume I.

## 🛠️ Tecnologías utilizadas
* **Lenguajes:** Java, HTML5, CSS3
* **Framework / Herramientas:** Spring Boot, Maven
* **Control de versiones:** Git & GitHub
